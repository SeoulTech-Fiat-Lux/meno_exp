# 스네이크 요구사항

meno vs SFML 3 : LLM 생성 비교 실험

## 스네이크 게임 개발

- 이 문서는 LLM 생성 비교 실험에 쓰는 미니게임 중 스네이크의 요구사항을 정리함.
- 같은 명세를 meno 조건과 SFML 3.1 조건에 그대로 주며, LLM은 main.cpp 하나만 작성함.
- 창 제목은 "SNAKE"임.
- 색은 '화면 색' 절과 제공된 에셋을 따름.

## Major Functional Requirements

- 스네이크의 주요 기능적 요구사항(Functional Requirement)은 다음과 같음.
  - 타이틀·플레이·결과로 이어지는 화면 흐름
  - 보드와 뱀의 이동, 방향 전환
  - 먹이와 가속, 충돌과 종료
- 게임 실행 후 종료까지 거치는 기본 기능이며, 자세한 요구사항은 이어지는 절에서 설명함.

## Major Non-functional Requirements

- 주요 비기능적 요구사항(Non-Functional Requirement)은 다음과 같음.
  - 제공된 템플릿에서 main.cpp 한 파일로 오류 없이 빌드되어야 함.
  - 60 FPS 제한에서 프레임레이트와 무관하게 같은 속도로 진행해야 함.
  - 입력을 놓치지 않고 다음 갱신에 반영해야 함.
  - 입력 없이 실행해도 비정상 종료 없이 명세된 흐름을 보여야 함.
  - 이동 간격이 정확하고, 짧게 누른 방향키도 반영해야 함.
- 자세한 요구사항은 이어지는 절에서 설명함.

## 화면 흐름과 공통 조작

- 창은 960×540이며, 제목 표시줄에는 "SNAKE"을 표시해야 함.
- 화면은 타이틀 → 플레이 → 결과 순서로 진행함.
  - 타이틀: 게임 이름 "SNAKE"(창 제목과 같음)과 "PRESS ENTER"를 표시. Enter를 누르거나 2초가 지나면 플레이 시작.
  - 결과: 결과 문구, 최종 점수, "R: RESTART  ESC: QUIT"를 표시.
- 결과 화면에서 R을 누르면 게임 상태를 모두 초기화하고(프로그램이 켜져 있는 동안 유지한다고 명세에 적힌 기록은 제외) 플레이를 다시 시작함 (타이틀은 거치지 않음).
- Esc는 어느 화면에서든 프로그램을 종료함. 창 닫기 버튼도 같음.
- 화면 문구는 영문 대문자이며, 명세에 적힌 문자열을 그대로 씀.
- 글자는 fonts/game.ttf로 그리며, 크기는 16의 배수(16·32·48px)로 함.
- 효과음은 명세에 지정된 사건에서, 지정된 파일로만 재생함.

## 보드와 이동

- 화면 위쪽 30px는 점수 표시줄("SCORE 0")이고, 그 아래는 칸 크기 30px의 32×17칸 보드임.
- 뱀은 길이 3으로 시작함. 머리는 (16, 8)칸에서 오른쪽을 향하고(칸 좌표는 왼쪽 위 칸이 (0, 0)인 (열, 행)), 몸은 머리 왼쪽 2칸에 놓임. 각 칸은 칸 안에 1px 여백을 둔 28×28 사각형으로 그리며, 머리와 몸은 색을 다르게 함.
- 뱀은 0.125초마다 한 칸씩 전진함.
- 방향키와 WASD로 방향을 바꿈. 진행 방향의 정반대로는 바꿀 수 없음.
- 한 이동 간격 안에 누른 방향은 최대 2개까지 순서대로 보관해, 이어지는 이동에 하나씩 적용함.
  - 예: ↑ 다음 ←를 빠르게 누르면 두 칸에 걸쳐 방향을 꺾음.
  - 마지막으로 보관된 방향(없으면 현재 진행 방향)과 같거나 정반대인 입력은 버림.

## 먹이와 종료

- 먹이는 뱀이 없는 칸 중 무작위 한 칸에 항상 하나 있음. 머리가 먹이 칸에 들어가면 길이 +1, 점수 +10, point.wav 재생 후 새 먹이를 놓음. 먹이는 칸 가운데에 둔 반지름 12의 원으로 그림.
- 먹이를 5개 먹을 때마다 이동 간격에 0.9를 곱함. 최소 0.06초.
- 머리가 보드 밖으로 나가거나 몸에 닿으면 lose.wav를 재생하고 결과 화면으로 감.
  - 이번 이동에서 꼬리가 빠져나가는 칸은 충돌로 보지 않음.
  - 단, 먹이를 먹는 이동에서는 꼬리가 그대로 있으므로 그 칸도 충돌로 봄.
- 결과 화면 문구는 "GAME OVER", 점수는 "SCORE 120" 형식임.
- 플레이 중에는 bgm_snake.ogg를 볼륨 40%로 반복 재생하고, 결과 화면에서는 멈춤.

## 화면 색

- 보드 배경: #0E1A12
- 점수 표시줄: #1F3A26
- 뱀 몸: #5FCB5F
- 뱀 머리: #B6F2A0
- 먹이: #E5533D
- 글자: #E8F5E9
- 텍스처가 있는 요소는 텍스처의 색을 그대로 씀.

## 이동 정확도와 무입력 실행

- 가속 전 10초 동안의 이동 횟수가 기대값 80회와 ±2회 이내여야 함.
- 이동 간격보다 짧게 눌렀다 뗀 방향키도 반영되어야 함 (방향 보관 한도 2개 안에서).
- 무입력 실행: 뱀이 오른쪽으로 전진해 오른쪽 벽에 부딪히고 결과 화면으로 가야 함.
  - 예상 흐름 (실행 시작 기준, 근사값): 0초 타이틀 → 2초 플레이 시작, 오른쪽 전진 → 약 4초 16번째 이동에서 벽 충돌, 결과 화면

## 코드와 빌드

- 코드는 main.cpp 한 파일이며, 제공된 CMakeLists.txt와 assets/는 수정하지 않음.
- meno 조건은 meno 공개 헤더만 쓰고 SFML 헤더를 직접 include하지 않음. SFML 조건은 SFML 3.1 모듈만 씀. 두 조건 모두 C++20 표준 라이브러리 외의 라이브러리는 쓰지 않음.
- 기준 환경에서 오류 없이 빌드되어야 함.
- 에셋을 읽지 못하면 실패한 경로를 표준 에러에 출력하고 종료 코드 1로 끝내야 함.

## 실행 품질

- 프레임은 60 FPS로 제한함. 모든 속도와 시간은 초 단위이며, 프레임레이트가 달라져도 게임 진행 속도는 같아야 함.
- 키와 마우스 입력은 다음 갱신에 반영하며, 한 프레임보다 짧게 눌렀다 뗀 입력도 놓치지 않아야 함.
- 입력 없이 10초 실행하는 동안 비정상 종료나 처리되지 않은 예외가 없어야 함. Esc나 창 닫기로 끝나면 종료 코드 0.
- 기준 환경에서 프레임 시간 95백분위가 20ms 이하여야 함.
  - 이 항목은 측정 하니스로만 확인함 (플레이 채점 제외).

## 게임 실행 환경

- 기준 환경: Ubuntu 24.04, GCC 13.3, CMake 3.28 이상
- SFML 3.1.0 (meno의 백엔드와 같은 버전)
- 화면 없는 실행은 xvfb-run을 씀.
- 제공물: 조건별 CMakeLists.txt 템플릿과 공통 assets/ 폴더. 두 조건이 같은 에셋을 씀.
- 에셋은 상대 경로 assets/…로 엶. 실행 파일은 assets/와 같은 폴더에 있으며, 그 폴더를 작업 디렉터리로 하여 실행함.
- 이 게임이 쓰는 에셋 (assets/…):
  - fonts/game.ttf
  - sfx/point.wav
  - sfx/lose.wav
  - music/bgm_snake.ogg

## 주의 사항

- 명세의 수치와 문자열은 정확히 따라야 함.
- 색과 그림은 명세와 제공된 에셋에 정한 것을 씀.
- 명세가 모호하면 가장 단순한 해석을 택함.
