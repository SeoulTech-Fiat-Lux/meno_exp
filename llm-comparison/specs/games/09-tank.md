# 2인 탱크 대전 요구사항

meno vs SFML 3 : LLM 생성 비교 실험

## 2인 탱크 대전 게임 개발

- 이 문서는 LLM 생성 비교 실험에 쓰는 미니게임 중 2인 탱크 대전의 요구사항을 정리함.
- 같은 명세를 meno 조건과 SFML 3.1 조건에 그대로 주며, LLM은 main.cpp 하나만 작성함.
- 창 제목은 "TANK DUEL"임.
- 두 사람이 한 키보드로 탱크를 조종하며, 화면을 반씩 나눠 서로를 쏘는 게임임.
- 색은 '화면 색' 절과 제공된 에셋을 따름.

## Major Functional Requirements

- 2인 탱크 대전의 주요 기능적 요구사항(Functional Requirement)은 다음과 같음.
  - 타이틀·플레이·결과로 이어지는 화면 흐름
  - 고정된 맵과 부서지는 벽
  - 탱크의 회전·이동과 충돌
  - 사격, 라운드와 승패
  - 화면 분할과 미니맵
- 게임 실행 후 종료까지 거치는 기본 기능이며, 자세한 요구사항은 이어지는 절에서 설명함.

## Major Non-functional Requirements

- 주요 비기능적 요구사항(Non-Functional Requirement)은 다음과 같음.
  - 제공된 템플릿에서 main.cpp 한 파일로 오류 없이 빌드되어야 함.
  - 60 FPS 제한에서 프레임레이트와 무관하게 같은 속도로 진행해야 함.
  - 입력을 놓치지 않고 다음 갱신에 반영해야 함.
  - 입력 없이 실행해도 비정상 종료 없이 명세된 흐름을 보여야 함.
  - 회전한 탱크가 벽을 뚫지 않고, 두 화면과 미니맵이 같은 상태를 보여야 함.
- 자세한 요구사항은 이어지는 절에서 설명함.

## 화면 흐름과 공통 조작

- 창은 960×540이며, 제목 표시줄에는 "TANK DUEL"을 표시해야 함.
- 화면은 타이틀 → 플레이 → 결과 순서로 진행함.
  - 타이틀: 게임 이름 "TANK DUEL"(창 제목과 같음)과 "PRESS ENTER"를 표시. Enter를 누르거나 2초가 지나면 플레이 시작.
  - 결과: 결과 문구, 최종 점수, "R: RESTART  ESC: QUIT"를 표시.
- 결과 화면에서 R을 누르면 게임 상태를 모두 초기화하고(프로그램이 켜져 있는 동안 유지한다고 명세에 적힌 기록은 제외) 플레이를 다시 시작함 (타이틀은 거치지 않음).
- Esc는 어느 화면에서든 프로그램을 종료함. 창 닫기 버튼도 같음.
- 화면 문구는 영문 대문자이며, 명세에 적힌 문자열을 그대로 씀.
- 글자는 assets/fonts/game.ttf로 그리며, 크기는 16의 배수(16·32·48px)로 함.
- 효과음은 명세에 지정된 사건에서, 지정된 파일로만 재생함.

## 맵과 화면

- 월드는 1440×1080이며, 이어지는 절의 24×18 문자 지도로 정함. 한 칸은 60×60px임.
- 기호: # 부서지지 않는 벽(assets/textures/tank_steel.png), b 부서지는 벽(assets/textures/tank_brick.png), . 빈 칸, 1·2 각 플레이어의 시작 칸.
- 화면은 세로로 반씩 나눔. 왼쪽 480×540은 1P 탱크를, 오른쪽 480×540은 2P 탱크를 가운데에 두고 보여 줌. 카메라는 월드 밖이 보이지 않도록 월드 안으로 제한하며, 두 화면 사이에 4px 세로선을 그림.
- 화면 아래 가운데(왼쪽 위 (384, 388))에 월드 전체를 192×144로 줄여 보여 주는 미니맵을 두 화면과 세로선 위에 그림. 월드 좌표를 1/7.5로 줄여 도형으로 그리며, 벽 칸은 8×8, 탱크는 중심에 6×6, 총알은 중심에 2×2 사각형임.
- 각 화면의 왼쪽 위에 "P1 HP 3  WINS 0"(오른쪽 화면은 P2) 형식으로 표시함.
- 플레이 중에는 assets/music/bgm_tank.ogg를 볼륨 40%로 반복 재생하고, 결과 화면에서는 멈춤.

## 맵 지도

- 지도 한 줄이 맵의 한 행이며, 위에서부터 0~17행, 왼쪽에서부터 0~23열임.
- 180° 회전 대칭이라 두 플레이어의 조건이 같음.
- 1P 시작: 2행 2열 칸 가운데. 2P 시작: 15행 21열 칸 가운데.
- 부서지지 않는 벽 128칸(테두리 포함), 부서지는 벽 24칸.

## 탱크

- 탱크는 assets/textures/tank_p1.png, assets/textures/tank_p2.png(각 40×32, 오른쪽을 향한 그림)로 그림. 충돌 영역은 그림과 같은 40×32 사각형이며 탱크와 함께 회전함.
- 1P는 W·S로 앞뒤, A·D로 회전, Space로 사격함. 2P는 ↑·↓로 앞뒤, ←·→로 회전, Enter로 사격함. A·←는 반시계, D·→는 시계 방향이며, 사격은 키를 누른 순간에만 함.
- 앞으로 160 px/s, 뒤로 100 px/s 움직이고 초당 180° 회전함. 1P는 오른쪽(0°), 2P는 왼쪽(180°)을 향해 시작 칸 가운데에서 시작함.
- 이동이나 회전 뒤에 벽 또는 상대 탱크와 겹치면, 그 틱의 이동과 회전을 모두 취소함.

## 사격과 라운드

- 사격은 0.5초에 한 번까지이며, 탱크마다 총알은 동시에 3개까지만 있을 수 있음. 총알은 반지름 4의 원이며, 탱크 중심에서 바라보는 방향으로 28px 앞에서 400 px/s로 날아가고 assets/sfx/shoot.wav를 재생함. 총알은 쏜 플레이어의 색으로 그림.
- 총알이 벽에 닿으면 없어짐. 부서지는 벽은 세 번 맞으면 없어짐. 자기 총알은 자기 탱크에 맞지 않음.
- 총알이 상대 탱크에 맞으면 총알이 없어지고 상대 HP가 1 줄며 assets/sfx/hit.wav를 재생함. HP는 3에서 시작함.
- HP가 0이 되면 assets/sfx/explode.wav를 재생하고 라운드가 끝나며, 상대가 라운드를 이김. 같은 틱에 둘 다 0이 되면 무승부(승수 변화 없음)임. 라운드가 끝나면 남은 총알을 모두 없애고, 2초 동안 두 탱크는 움직이거나 쏘지 않음. 2초 뒤 맵과 탱크(위치·방향·HP·사격 대기)를 처음 상태로 되돌려 다음 라운드를 시작함.
- 먼저 3라운드를 이기면 그 라운드의 2초가 지난 뒤 결과 화면으로 감. 문구는 "P1 WINS" 또는 "P2 WINS", 점수는 "3 : 1" 형식(1P : 2P).

## 화면 색

- 바닥(배경): #3A3F2E
- 1P 총알: #4FC3F7
- 2P 총알: #FF8A65
- 두 화면 사이 세로선: 흰색 #FFFFFF
- 미니맵: 바탕 검은색 #000000, 테두리 흰색 #FFFFFF 1px
- 미니맵 벽: 부서지지 않는 벽 #4D5971, 부서지는 벽 #79362A
- 미니맵 탱크·총알: 그 플레이어의 총알 색
- 글자: 흰색 #FFFFFF
- 텍스처가 있는 요소는 텍스처의 색을 그대로 씀.

## 판정과 무입력 실행

- 회전한 탱크가 벽이나 상대 탱크를 뚫거나, 겹친 채 빠져나오지 못하는 일이 없어야 함.
- 총알이 벽이나 탱크를 뚫고 지나가지 않아야 함. (틱당 약 6.7px < 가장 얇은 겹침 구간 40px)
- 두 화면과 미니맵은 같은 틱의 상태를 보여야 함. 창 크기를 바꿔도 전체 16:9 비율과 두 화면·미니맵의 배치가 유지되어야 함 (남는 부분은 검은 띠).
- 무입력 실행: 두 화면에 각 탱크가 보이고 미니맵에 두 탱크가 표시되며, 그 뒤로는 변화가 없어야 함.
  - 예상 흐름 (실행 시작 기준, 근사값): 0초 타이틀 → 2초 라운드 1 시작, 두 화면과 미니맵 표시 → 2~10초 변화 없음

## 코드와 빌드

- 코드는 main.cpp 한 파일이며, 제공된 CMakeLists.txt와 assets/는 수정하지 않음.
- meno 조건은 meno 공개 헤더만 쓰고 SFML 헤더를 직접 include하지 않음. SFML 조건은 SFML 3.1 모듈만 씀. 두 조건 모두 C++20 표준 라이브러리 외의 라이브러리는 쓰지 않음.
- 기준 환경에서 오류 없이 빌드되어야 함.
- 에셋을 읽지 못하면 실패한 경로를 표준 에러에 출력하고 종료 코드 1로 끝내야 함.

## 실행 품질

- 프레임은 60 FPS로 제한함. 모든 속도와 시간은 초 단위이며, 프레임레이트가 달라져도 게임 진행 속도는 같아야 함.
- 키와 마우스 입력은 다음 갱신에 반영하며, 한 프레임보다 짧게 눌렀다 뗀 입력도 놓치지 않아야 함.
- 입력 없이 10초 실행하는 동안 비정상 종료나 처리되지 않은 예외가 없어야 함. Esc나 창 닫기로 끝나면 종료 코드 0.
- 기준 환경에서 프레임 시간 95백분위가 20ms 이하여야 함.
  - 이 항목은 측정 하니스로만 확인함 (플레이 채점 제외).

## 게임 실행 환경

- 기준 환경: Ubuntu 24.04, GCC 13.3, CMake 3.28 이상
- SFML 3.1.0 (meno의 백엔드와 같은 버전)
- 화면 없는 실행은 xvfb-run을 씀.
- 제공물: 조건별 CMakeLists.txt 템플릿과 공통 assets/ 폴더. 두 조건이 같은 에셋을 씀.
- 에셋은 상대 경로 assets/…로 엶. 실행 파일은 assets/와 같은 폴더에 있으며, 그 폴더를 작업 디렉터리로 하여 실행함.
- 텍스처는 제공된 크기 그대로 게임 안에서 그림.

## 제공 에셋

- 이 게임이 쓰는 에셋:
  - assets/fonts/game.ttf
  - assets/sfx/shoot.wav, assets/sfx/hit.wav, assets/sfx/explode.wav
  - assets/music/bgm_tank.ogg
  - assets/textures/tank_p1.png (40×32), assets/textures/tank_p2.png (40×32)
  - assets/textures/tank_steel.png (60×60), assets/textures/tank_brick.png (60×60)

## 주의 사항

- 명세의 수치와 문자열은 정확히 따라야 함.
- 색과 그림은 명세와 제공된 에셋에 정한 것을 씀.
- 명세가 모호하면 가장 단순한 해석을 택함.
