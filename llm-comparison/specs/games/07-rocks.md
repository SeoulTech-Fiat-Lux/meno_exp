# 소행성 슈팅 요구사항

meno vs SFML 3 : LLM 생성 비교 실험

## 소행성 슈팅 게임 개발

- 이 문서는 LLM 생성 비교 실험에 쓰는 미니게임 중 소행성 슈팅의 요구사항을 정리함.
- 같은 명세를 meno 조건과 SFML 3.1 조건에 그대로 주며, LLM은 main.cpp 하나만 작성함.
- 창 제목은 "ROCK FIELD"임.
- 회전하고 관성으로 움직이는 우주선으로, 쪼개지는 운석을 쏘아 없애는 게임임.
- 색은 '화면 색' 절과 제공된 에셋을 따름.

## Major Functional Requirements

- 소행성 슈팅의 주요 기능적 요구사항(Functional Requirement)은 다음과 같음.
  - 타이틀·플레이·결과로 이어지는 화면 흐름
  - 우주선의 회전, 추진, 관성, 화면 끝 이어짐
  - 사격과 운석 분열
  - 목숨, 웨이브, 점수
- 게임 실행 후 종료까지 거치는 기본 기능이며, 자세한 요구사항은 이어지는 절에서 설명함.

## Major Non-functional Requirements

- 주요 비기능적 요구사항(Non-Functional Requirement)은 다음과 같음.
  - 제공된 템플릿에서 main.cpp 한 파일로 오류 없이 빌드되어야 함.
  - 60 FPS 제한에서 프레임레이트와 무관하게 같은 속도로 진행해야 함.
  - 입력을 놓치지 않고 다음 갱신에 반영해야 함.
  - 입력 없이 실행해도 비정상 종료 없이 명세된 흐름을 보여야 함.
  - 총알이 운석을 뚫지 않고, 화면 끝을 넘어도 속도와 방향이 유지되어야 함.
- 자세한 요구사항은 이어지는 절에서 설명함.

## 화면 흐름과 공통 조작

- 창은 960×540이며, 제목 표시줄에는 "ROCK FIELD"을 표시해야 함.
- 화면은 타이틀 → 플레이 → 결과 순서로 진행함.
  - 타이틀: 게임 이름 "ROCK FIELD"(창 제목과 같음)과 "PRESS ENTER"를 표시. Enter를 누르거나 2초가 지나면 플레이 시작.
  - 결과: 결과 문구, 최종 점수, "R: RESTART  ESC: QUIT"를 표시.
- 결과 화면에서 R을 누르면 게임 상태를 모두 초기화하고(프로그램이 켜져 있는 동안 유지한다고 명세에 적힌 기록은 제외) 플레이를 다시 시작함 (타이틀은 거치지 않음).
- Esc는 어느 화면에서든 프로그램을 종료함. 창 닫기 버튼도 같음.
- 화면 문구는 영문 대문자이며, 명세에 적힌 문자열을 그대로 씀.
- 글자는 assets/fonts/game.ttf로 그리며, 크기는 16의 배수(16·32·48px)로 함.
- 효과음은 명세에 지정된 사건에서, 지정된 파일로만 재생함.

## 우주선

- 우주선은 assets/textures/rock_ship.png(32×32, 오른쪽을 향한 그림)로 그림. 화면 가운데에서 위(270°)를 향해 멈춘 채 시작함. 충돌 영역은 반지름 12의 원임.
- ←·A로 반시계, →·D로 시계 방향으로 초당 240° 회전함.
- ↑·W를 누르고 있으면 바라보는 방향으로 300 px/s²로 가속하며, 최대 속력은 360 px/s임. 누르지 않으면 속력이 1초마다 절반으로 줄어듦.
- 화면 밖으로 나간 우주선, 총알, 운석은 반대쪽 끝에서 다시 나타남 (중심 좌표 기준). 충돌도 중심 좌표 기준으로만 판정하며, 화면 끝에 걸친 경우를 따로 처리하지 않음.
- Space를 누른 순간 총알을 쏘고 assets/sfx/shoot.wav를 재생함. 총알은 반지름 2의 원이며, 우주선 앞 16px 지점에서 바라보는 방향으로 600 px/s로 날아감. 1초 뒤 사라지며, 동시에 4개까지만 있을 수 있음.

## 운석

- 운석은 세 가지임: 큰 것(반지름 40, 20점, 60 px/s), 중간(반지름 24, 50점, 90 px/s), 작은 것(반지름 12, 100점, 130 px/s). 충돌 영역은 반지름과 같은 원임.
- 운석은 꼭짓점 10개의 다각형 외곽선으로 그림. 꼭짓점은 36° 간격이며, 중심과의 거리는 꼭짓점마다 반지름의 0.8~1.0배에서 무작위로 정하며, 운석이 생길 때 한 번 정하고 바꾸지 않음.
- 웨이브 n은 큰 운석 3 + n개(최대 10개)로 시작함. 운석은 화면 가운데에서 300px 떨어진 원 위의 무작위 위치에 생기며, 첫 번째 운석은 화면 가운데를 향해, 나머지는 무작위 방향으로 움직임.
- 총알이 운석에 맞으면 둘 다 없어지고 점수를 얻으며 assets/sfx/explode.wav를 재생함. 큰 운석과 중간 운석은 같은 자리에서 한 단계 작은 운석 2개로 쪼개지며, 두 운석은 원래 방향에서 ±30° 돌아간 방향으로 움직임.
- 운석을 모두 없애면 남은 총알도 모두 지우고, 2초 뒤 다음 웨이브를 시작함.

## 목숨과 화면

- 우주선이 운석에 닿으면 목숨을 하나 잃고 assets/sfx/lose.wav를 재생함. 우주선은 사라졌다가 2초 뒤 화면 가운데에서 위를 향해 멈춘 채 다시 나타남. 부딪힌 운석은 그대로 움직이며 점수는 없음. 우주선이 사라진 동안에는 회전·추진·사격 입력을 받지 않음.
- 다시 나타난 뒤 2초 동안은 운석에 닿아도 아무 일이 없으며, 0.1초마다 보였다 안 보였다 함.
- 화면 위쪽 왼쪽에 "SCORE n", 가운데에 "WAVE n", 오른쪽에 "SHIPS n"을 표시함. 목숨은 3개로 시작함.
- 목숨이 0이 되면 결과 화면으로 감. 문구는 "GAME OVER", "SCORE n", "WAVE n".
- 플레이 중에는 assets/music/bgm_rocks.ogg를 볼륨 40%로 반복 재생하고, 결과 화면에서는 멈춤.

## 화면 색

- 배경: 검은색 #000000
- 운석 외곽선: 흰색 #FFFFFF, 두께 2px
- 총알: 흰색 #FFFFFF
- 글자: 흰색 #FFFFFF
- 텍스처가 있는 요소는 텍스처의 색을 그대로 씀.

## 판정과 무입력 실행

- 총알이 운석을 뚫고 지나가지 않아야 함. (틱당 10px < 가장 작은 겹침 구간 28px)
- 화면 끝을 넘을 때 속도와 방향을 유지한 채 반대쪽으로 이어져야 함.
- 다 쓴 총알과 없어진 운석은 남지 않고 삭제되어야 함. 웨이브가 끝나면 운석과 총알 수가 0이어야 함.
- 무입력 실행: 운석이 가운데의 우주선에 부딪혀 SHIPS가 3에서 2가 되어야 함 (보통 가운데를 향해 오는 첫 운석이 부딪힘).
  - 예상 흐름 (실행 시작 기준, 근사값): 0초 타이틀 → 2초 웨이브 1 시작 → 약 5~6초 첫 충돌 (SHIPS 2) → 약 7~8초 우주선 다시 나타남

## 코드와 빌드

- 코드는 main.cpp 한 파일이며, 제공된 CMakeLists.txt와 assets/는 수정하지 않음.
- meno 조건은 meno 공개 헤더만 쓰고 SFML 헤더를 직접 include하지 않음. SFML 조건은 SFML 3.1 모듈만 씀. 두 조건 모두 C++20 표준 라이브러리 외의 라이브러리는 쓰지 않음.
- 기준 환경에서 오류 없이 빌드되어야 함.
- 에셋을 읽지 못하면 실패한 경로를 표준 에러에 출력하고 종료 코드 1로 끝내야 함.

## 실행 품질

- 프레임은 60 FPS로 제한함. 모든 속도와 시간은 초 단위이며, 프레임레이트가 달라져도 게임 진행 속도는 같아야 함.
- 키와 마우스 입력은 다음 갱신에 반영하며, 한 프레임보다 짧게 눌렀다 뗀 입력도 놓치지 않아야 함.
- 입력 없이 10초 실행하는 동안 비정상 종료나 처리되지 않은 예외가 없어야 함. Esc나 창 닫기로 끝나면 종료 코드 0.
- 기준 환경에서 프레임 시간 95백분위가 20ms 이하여야 함.
  - 이 항목은 측정 하니스로만 확인함 (플레이 채점 제외).

## 게임 실행 환경

- 기준 환경: Ubuntu 24.04, GCC 13.3, CMake 3.28 이상
- SFML 3.1.0 (meno의 백엔드와 같은 버전)
- 화면 없는 실행은 xvfb-run을 씀.
- 제공물: 조건별 CMakeLists.txt 템플릿과 공통 assets/ 폴더. 두 조건이 같은 에셋을 씀.
- 에셋은 상대 경로 assets/…로 엶. 실행 파일은 assets/와 같은 폴더에 있으며, 그 폴더를 작업 디렉터리로 하여 실행함.
- 텍스처는 제공된 크기 그대로 게임 안에서 그림.

## 제공 에셋

- 이 게임이 쓰는 에셋:
  - assets/fonts/game.ttf
  - assets/sfx/shoot.wav
  - assets/sfx/explode.wav
  - assets/sfx/lose.wav
  - assets/music/bgm_rocks.ogg
  - assets/textures/rock_ship.png (32×32)

## 주의 사항

- 명세의 수치와 문자열은 정확히 따라야 함.
- 색과 그림은 명세와 제공된 에셋에 정한 것을 씀.
- 명세가 모호하면 가장 단순한 해석을 택함.
