# 요구사항 문서 변경 기록

## 2026-11-14 — pptx → md 전환과 빌드 대조

`games/*.md`를 LLM에게 주는 원본으로 삼는다. `pptx/`는 발표용 사본이며, 아래 내용 수정은 pptx에도
똑같이 반영했다. 변환은 `pptx2md.py`로 했다.

### 내용 수정 (pptx·md 모두)

| 문서 | 이전 | 이후 | 이유 |
|---|---|---|---|
| 게임 11종 | 에셋 경로는 실행 파일 기준 상대 경로 assets/…임. | 에셋은 상대 경로 assets/…로 엶. 실행 파일은 assets/와 같은 폴더에 있으며, 그 폴더를 작업 디렉터리로 하여 실행함. | 상대 경로는 작업 디렉터리 기준으로 열린다. 실행 파일 위치를 구하는 코드를 유도하지 않도록 명확히 함. 빌드 템플릿이 assets/를 실행 파일 옆에 복사하고, 하니스가 그 폴더에서 실행한다. |
| 팀 내부 | 보완 예정인 다각형 그리기의 검증 대상이기도 함. | #35에서 보완한 다각형 외곽선 그리기의 검증 대상이기도 함. | #35 완료(drawPolygon 외곽선) |
| 팀 내부 | 보완 예정인 원호·런타임 색의 검증 대상이기도 함. | #35에서 보완한 런타임 색(폭발 원의 두 색 번갈아 쓰기)의 검증 대상이기도 함. | #35 완료. 미사일 방어 명세에 원호가 없어 '원호'를 뺌 (원호가 필요하면 명세에 추가할 것) |

### md 전환에 따른 수정 (md만)

- 화면 배치 예시 그림이 없으므로 "오른쪽은 화면 배치 예시이며, …" 문장을 "색은 '화면 색' 절과 제공된 에셋을 따름."으로 줄임.
  예시 그림은 사람용으로 `layout/`에 PNG로 두며, LLM에게는 주지 않는다.
- "슬라이드"를 "절"로 바꿈 (이어지는 절, 앞 절, '화면 색' 절).
- 발표자 노트(계산 근거)를 `rationale.md`로 옮김. LLM에게 주지 않는다. 노트의 `scratchpad/sim/` 경로는
  `sim/`으로 바꿨으며, 해당 시뮬레이션 스크립트(chase.py, tank.py, survivor_noinput.py)를 `specs/sim/`에 넣어야 함.
- 팀 내부 문서의 "계산 근거는 각 게임 요구사항 문서의 비기능 슬라이드 노트에 있음" → "rationale.md에 있음".

### 에셋 수정

- 폰트 폴더 `font/` → `fonts/`. 요구사항 문서 11종과 에셋 사양표가 모두 `fonts/game.ttf`라고 적고 있음.

### 검산 결과 (수정 없음)

- 에셋 52종의 크기·형식이 사양표와 일치함 (텍스처 크기, WAV 44.1kHz 16비트 모노, OGG 44.1kHz 스테레오).
- 폰트(Neo둥근모)에 필요한 글자(A–Z, 0–9, 공백, % + . :)가 모두 있음.
- 팩맨류 지도: 21×21, 점 160개, 파워 알 4개, 시작·문·집 위치 일치, 모든 통로 연결, 막다른 길 없음.
- 2인 탱크 대전 지도: 24×18, 부서지지 않는 벽 128칸, 부서지는 벽 24칸, 180° 회전 대칭, 시작 칸 일치.
- 기준 환경(Ubuntu 24.04, GCC 13.3, CMake 3.28, SFML 3.1.0)에서 두 조건의 템플릿이 빌드되고, 에셋 로드 실패 시
  종료 코드 1, Esc 종료 시 0, 무입력 실행·녹화·프레임 시간 측정이 동작함을 확인함.

### 고치지 않고 남긴 것 (팀 결정 필요)

- 탑다운 슈터·서바이버류의 "적 200(400)마리 … 프레임 시간 95백분위" 항목은 무입력 실행으로는 그 상황에 도달하지
  않는다. 측정 방법을 정하거나, 대량 오브젝트 성능은 #30 벤치마크로 넘기는 것을 권장.
- 에셋 사양표의 '게임별 색' 시트에 2인 탱크 대전의 미니맵 벽·탱크·총알 색(#4D5971, #79362A 등)이 빠져 있음.
